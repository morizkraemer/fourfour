# Documentation index

The full index is [README.md](README.md). Agent rules are [../AGENTS.md](../AGENTS.md).

## Source

| Path | What |
|---|---|
| `pioneer-usb-writer/` | Pioneer USB format library |
| `pioneer-library/` | SQLite library and USB export |
| `pioneer-test-ui/` | Tauri shell |
| `app/` | Svelte desktop UI |
| `analysis/` | Python CLI (`fourfour-analyze`, `fourfour-benchmark`) |
| `benchmark/scripts/` | Benchmark scripts that call the analysis CLI |
| `ui/waveform/` | Waveform dev harness (`./waveform-dev`) |
| `prototyping/` | Design-system playground |

`mockup/` and `designs/` are static mockups, not the app.

`benchmark/` is in this repo. Samplebase does not hold this benchmark code. Local datasets, results, logs, and cache under `benchmark/` are gitignored.
