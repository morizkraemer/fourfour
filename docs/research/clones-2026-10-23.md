## Headline
- The "lite" clone is almost certainly **rbxport** (github.com/chrisle/rbxport, 262★, created 2026-09-25): "rekordbox-inspired", "fewer features", crates prefixed `rbl-`, test env `RB_LITE_TEST`. **GPL-2.0-or-later → ideas only.**

## By fourfour area

### Startup + big libraries (rbxport, ideas only)
- Columnar in-memory index, reading only live rows and needed columns, filtered in SQL: `crates/rbl-index/src/load.rs`; packed string arena `strings.rs`.
- Checksummed, versioned on-disk snapshot cache keyed on DB identity + schema + change counter (`MAX(rb_local_usn)` + row count), not mtimes: `rbl-index/src/cache.rs`. SQLCipher open ≈680 ms, 543 ms of it decryption.
- Snapshot prepared on a thread while the DB opens (`src-tauri/src/lib.rs` `spawn_library_load`); sort ranks + search index on scoped threads (`rbl-index/src/view.rs:451`).
- Windowed IPC: 64-row pages, LRU of 100 pages outside React state (`src/lib/rowCache.ts`); TanStack Virtual, overscan 16; sort/filter/search in Rust.
- Window shown after first commit with a 5 s rescue timer (`src-tauri/src/startup.rs`). CI perf budgets (`perf-budgets.json`: initial chunk 150 KB gz, first rows 300 ms, frame cost 3 ms). Claimed ~1.5 s start, <200 MB on 38k tracks (self-reported).
- cyanbox: waveform previews stored apart from detail, versioned header to find stale ones without unpacking (`src/core/wavestore.c`).

### Analysis
- rbxport: all audio-only stages in parallel on `thread::scope` from one mono f32 decode (`rbl-analysis/src/lib.rs:108`, `rbl-audio` `decode_mono`). Grid: spectral flux, autocorrelation × √Fourier × prior 70–200 BPM, kick-attack fit. Key: HPCP + EDMA profile.
- **cyanbox key (BSD-2, copyable):** decimate to ~11 kHz, 8192-pt STFT, tuning, whitening, 3 chroma bands (bass/mid/treble), 24 fitted templates with a major bias, softmax confidence. Self-reported 64.7% exact on GiantSteps (604, held out) vs libKeyFinder 60.4%; ~110 ms per 5 min. `src/analysis/key.c`, `docs/KEY.md`.
- **cyanbox beats:** CPU path ~290 ms per 4.5 min; fine envelopes only in an 8192-sample window around each beat (`docs/BEATS.md` §1). Beat This! (MIT code + weights) as GGUF f16 on Vulkan: 0.2 s per 4 min on an RX 6900 XT vs 11 s PyTorch CPU (`src/ml/beatthis.c`).
- MP3 timeline rule (cyanbox `src/audio/mp3.c`): a leading Xing/Info frame counts as one silent frame unless one of the first four frames changes version/layer/rate/mode; rbxport measured 86/200 files 1152 samples later than a decoder that drops the tag frame. Relevant to Q15's mp3 delay finding.
- dj-usb-tkit (AGPL, ideas): `refine_bpm` phase-coherence refinement in 0.01 BPM steps with family checks; "index first, analyse later".
- Vynull (GPL, ideas): priority queue (deck/user waiting first, background never takes the last slot, duplicate requests join, concurrency bounded by memory ≈1.5 GB/track); phrases anchored to absolute ms.

### Rekordbox import
- rbxport (ideas): direct master.db read; drive path remap exactly like rekordbox (djmdProperty BaseDBDrive/CurrentDBDrive, case-insensitive prefix swap, `rbl-db/src/lib.rs:384`); Camelot/enharmonic key ranking (`rbl-index/src/key.rs`); USB import `src-tauri/src/usb_import.rs`.
- dj-usb-tkit (ideas): `rekordbox_import.rs:95`, merge policy where user edits win; Wine-prefix paths (`wine_paths.rs`).
- cratedrop (MIT): imported cues kept as protected manual data that survive re-analysis; tolerant reading of deck-written cues/history (`deploy/harvest.py`).
- Vynull (ideas): `import_masterdb.go`, `import_xml.go`, `import_traktor.go`.

### Sync, multi-USB, export safety
- rbxport (ideas): `commands.rs:1144` `sync_devices` builds the selection once, reads each track once, writes all sticks concurrently; one failing stick doesn't stop the others; duplicate roots rejected. Manifest with per-file receipts (size, ns mtime, ctime/inode), journaled publication with recovery, optional "Verify all files" (`docs/reference/usb-export-pipeline.md`; `crates/rbl-export/src/{incremental,reconcile,snapshot,verification}.rs`, `rbl-core/src/durable.rs`).
- cyanbox (BSD-2): 16-thread pool for small files and closes — FAT closes sleep ~0.1 s each, so 200 files ≈20 s serial vs ≈1 s pooled; audio through encode + write threads, 1 MiB pieces, 32-piece queue, `O_DIRECT` where possible (`src/export/export.c`). `cyanbox sync`/`pull` reads cues/history back by track id.
- baken (MIT): rekordbox-style `/Contents/<Artist>/<Album>/<file>` naming (NFC, FAT-safe, 48-char cut, collisions) `layout.rs`; macOS NFD/NFC removal fix `fsname.rs`; filesystem + free-space check `volume.rs`; per-player format verdicts with explicit `Unknown` `cdjsafe/matrix.rs`.
- es-rekordbox-sdk (GPL, ideas): inspection returns a review token bound to the observed device state; no universal force action.

### Audio engine
- rbxport (ideas): cpal + rtrb, one decode thread per deck, callback only reads ring blocks, generation-tagged blocks so seeks discard stale audio, allocation-count test for the callback.
- cyanbox (BSD-2): RT thread without allocation or locks; feed thread woken by eventfd decodes chunks around the playhead; Catmull-Rom varispeed; Signalsmith Stretch for master tempo.

### UI
- rbxport: canvas waveforms, targeted refresh via a `library:changed` generation counter.
- cyanbox: waveform drawn by a fragment shader from the same bytes that go on the stick; redraw only on change.

### Format facts (brother's lane)
- baken (MIT): waveform rules fitted to 1,070 rekordbox 7.2 tracks (mono height/whiteness byte-exact on 99.5% of columns; 3-band constants) `anlz/generate/waveform.rs`; real PVB2 FLAC seek table (fourfour writes zeros, `pioneer-usb-writer/src/writer/anlz.rs:556`) `anlz/flac.rs`; PSSI XOR mask `anlz/pssi.rs`; ANLZ dir hash cross-check `anlz/hash.rs`.
- cratedrop (MIT): `build_pssi`; transfer curves; `ANALYSED_BITS = 41` (105 = +phrase).
- Booth 0.0.9 fixes that made a CDJ-3000 fw 3.22 accept its drive (Booth doesn't know which were necessary): table directory pointing all 20 tables at one empty page; a one-row history table; header page → first data page with free-slot fill; empty browse tables 17/18; 16 bytes after `len_file` in each ANLZ = `1, 0x10000, 0x10000, 0`; hot cues before memory cues in PCOB/PCO2; PWV7/6/4 band bytes ≤127 (PWV6 ≤45), low-mid-high order. Not yet checked against fourfour.
- cyanbox: PWAV min height 2, PWV2 min 1 (Nexus rejects zero columns); 64-entry hot-cue colour table; second format reference in `docs/{pdb,anlz,onelibrary,settings}.md`.

## Risks
- GPL/AGPL/BPSL/unlicensed code (rbxport, es-rekordbox-sdk, dj-usb-tkit, Vynull, Booth, djbooth): ideas only. cyanbox says it took facts, not code, from rbxport — copy cyanbox, not rbxport. rbxport's default build links GPL Rubber Band.
- Fitted constants are approximations (baken 1,070 tracks, cratedrop 6, rbxport 9); verify on hardware.
- Self-reported accuracy/hardware claims, unverified; cyanbox key numbers are on GiantSteps only.
- Fast churn: one-person, mostly AI-assisted projects under 3 months old.
- Provenance: DjManager firmware notes and rbxport disassembly notes derive from AlphaTheta binaries (EULA); design input only, never paste.
- Search gaps: GitHub search timed out; other new projects may exist. rekordlib (Zig) was not found this time.
